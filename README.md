# Exercícios Disciplina C111-A

Este repositório contém as soluções para os exercícios propostos da disciplina de Análise de Dados com Python.

## Informações Acadêmicas
**Instituição:** Inatel (Instituto Nacional de Telecomunicações)
**Professor:** Renzo Paranaíba Mesquita
**Disciplina:** Análise de Dados

## Objetivos
O objetivo desta disciplina é praticar os conceitos da análise de dados.
Ao final do curso espera-se que os alunos sejam capazes de entender a conceituação, terminologia, ferramentas e arquiteturas
em Big Data. Conhecer como Big Data pode transformar um negócio e conhecer as principais técnicas para análise de dados,
sua implementação e seu processamento.

## Tecnologias Utilizadas
Linguagem Python
IDE: Visual Studio Code
